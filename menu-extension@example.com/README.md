# Меню опций

Простое расширение GNOME Shell, которое отображает меню с двумя опциями в верхней панели.

## Установка

### Быстрая установка
Используйте скрипт установки:
```
./install.sh
```

### Активация расширения
В Wayland для обнаружения нового расширения необходимо перезапустить сессию GNOME:
1. Выйдите из системы
2. Войдите в систему снова
3. Активируйте расширение через приложение "Расширения" или командой:
   ```
   gnome-extensions enable menu-extension@example.com
   ```

### Ручная установка
1. Скопируйте содержимое папки `menu-extension@example.com` в `~/.local/share/gnome-shell/extensions/menu-extension@example.com/`
2. Скомпилируйте схему настроек:
   ```
   cd ~/.local/share/gnome-shell/extensions/menu-extension@example.com/schemas/
   chmod +x compile.sh
   ./compile.sh
   ```
3. Перезапустите сессию GNOME (выйдите и войдите снова)
4. Активируйте расширение через приложение "Расширения"

## Использование
Расширение отображает кнопку "Опции" в верхней панели. При клике на неё открывается меню с двумя переключателями. Состояние переключателей сохраняется между сеансами.

## Разработка и отладка
Для просмотра журналов и отладки используйте:
```
journalctl -f -o cat /usr/bin/gnome-shell
```
